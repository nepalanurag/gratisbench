    Splitting a PDF usually means one of two things: you want a few pages out of a long document, or you want to break a document into pieces. Maybe it is the first three pages of a report for a client, or chapters of a scanned book saved as separate files. Either way, the job is small and the usual tools make it annoying: upload limits, queues, watermarks, or a subscription for something you will do twice a year.

    This splitter works with page ranges. Tell it which pages you want, and it builds new PDFs containing exactly those pages. Separate groups with a semicolon and each group becomes its own file, so "1-3; 4-6" gives you two documents in one go. Like every FreeKit tool, everything happens in your browser. The PDF is never uploaded anywhere.

    Pages are extracted as-is, so the output keeps the original quality, selectable text, and links. Splitting does not touch the content of the pages; it just decides which ones go into each new file.

    How to use it

    1. Drop your PDF onto the box above, or click it to browse. The page count appears once it is read.
    2. Type the pages you want using numbers and ranges. Use commas inside one file ("1-3, 5") and semicolons to make separate files ("1-3; 4-6").
    3. Click "Split PDF". Each output file is built on your device.
    4. Download the files one by one from the results list.

    Common questions

    How do I write the page ranges?
    Use plain numbers and dashes. "5" means page 5. "1-3" means pages 1, 2 and 3. "1-3, 5" puts all of those pages into one file. If you want separate files, split the groups with a semicolon: "1-3; 4-6" produces two PDFs. Pages are numbered starting at 1, and reversed ranges like "5-3" are read as "3-5".
    Can I split a PDF into many files at once?
    Yes. Each semicolon-separated group becomes its own download, up to 50 groups per run. So "1-2; 3-4; 5-6; 7-8" gives you four files in a single pass. Each file is named split-part-1.pdf, split-part-2.pdf, and so on.
    Is this PDF splitter really free?
    Yes, completely. No daily limits, no watermarks, no locked features. Splitting is a local operation on your device, so it costs nothing to provide and there is nothing to upsell.
    Are my PDFs uploaded to a server?
    No. The file is read and split by code running in your browser. Nothing leaves your device, which makes this safe to use for contracts, statements, and other documents you would rather not upload.
    Will splitting change the quality of the pages?
    No. Pages are copied directly from the original into the new documents. Text stays selectable, links keep working, and images keep their original resolution.
    What if I enter a page number that does not exist?
    The tool checks every number against the actual page count and tells you exactly which entry is wrong, for example that page 40 does not exist in a 32-page document. Fix the range and try again.
    Why will my PDF not split?
    The most common reason is password protection: encrypted PDFs cannot be opened without the password. Remove the password in your PDF reader first. Damaged or non-standard files can also fail to load.
