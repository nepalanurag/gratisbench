Common questions

Is this signature generator really free? What is the catch?
Yes, and there is no catch to find. The usual catch with signature tools is a branding badge on the free tier that you pay to remove, or a subscription for "premium" templates. This tool has no branding to remove and no premium tier, because it runs entirely in your browser and produces a file you paste yourself. There is no service being metered, so there is nothing to charge for.
How do I add the signature to Gmail?
Click "Copy rich text" above, then in Gmail open Settings, "See all settings", scroll to the Signature section, and create a new signature. Click inside the signature box and paste. Gmail accepts the formatted content directly, so your name, accent color, and links arrive intact. Give the signature a name, set it as the default for new emails and replies, and scroll down to save.
How do I add the signature to Outlook?
Click "Copy rich text", then in Outlook on the web open Settings, "Mail", "Compose and reply", and paste into the email signature box. In classic desktop Outlook, go to File, Options, Mail, Signatures, create a new signature, and paste into the editor. Set it as the default for new messages. Outlook’s editor is finicky with complex HTML, which is why this tool keeps the markup deliberately simple.
Why does the HTML look so old-fashioned? Tables and inline styles?
Because email clients are stuck in 2005. Gmail strips <style> blocks and class attributes, and Outlook uses Word’s rendering engine for HTML. Tables with inline styles are the one format every major client renders consistently. A modern-looking signature built with flexbox and CSS classes would look great in your browser and fall apart in your recipient’s inbox. Boring markup is a feature here.
What is the difference between "Copy HTML" and "Copy rich text"?
"Copy HTML" copies the raw source code, useful if you want to inspect it, hand-edit it, or paste it into a system that takes HTML directly. "Copy rich text" copies the rendered signature, which is what you want for Gmail and Outlook: their signature boxes are rich-text editors, so pasting the rendered version keeps the formatting, colors, and links without you touching any code.
Will my signature work on phones?
Yes. The layouts are narrow by design: the two-column version is a photo beside a short text block, and everything stacks gracefully at small widths because email clients scale table content. Keep the text short and the photo small for the best results on mobile, and send yourself a test email to check it in your own client before relying on it.
Is my information private?
Yes. Everything you type is saved to your browser’s local storage on your own device so the form survives a refresh, and it is stated in the tool: saved in this browser only. Nothing is uploaded anywhere, because there is no server involved. Clearing your browser data erases it, so keep a copy of the HTML somewhere safe if you need it on another device.
Can I use my company logo instead of a photo?
Yes. The photo upload accepts any JPG or PNG, and it is shrunk to a small size before saving so it stays light in every email. For the two-column layout it renders as a round avatar, which suits a headshot; for a logo, the stacked layout shows it as a small rectangle and usually looks better. Keep logos simple and high-contrast, since they render small.
