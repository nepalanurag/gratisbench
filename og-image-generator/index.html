Bannerbear charges $49 a month to generate social card images through an API, which makes sense if you need ten thousand cards a month. If you need one card for your blog post, it is a strange price to pay. A social card is a colored rectangle with some text on it, and your browser draws rectangles and text for free.

This tool makes the card in front of you: type the headline, add a subline and a brand name, pick one of four sizes (the classic 1200x630 Open Graph card, a square, a wide 1600x900, or the 1200x675 X card), choose one of eight color themes and a background pattern, and download the PNG at full resolution. Long headlines wrap and shrink to fit automatically, so you never get text running off the edge.

Everything happens on the page with a live canvas preview, and nothing is uploaded anywhere. There is no API key, no template library to browse, and no monthly plan. If you need programmatic card generation at scale, Bannerbear is the honest answer; if you need a card for the thing you are publishing today, this is.

How to use it

  1. Pick a size: Open Graph 1200x630 for link previews, square for feeds, wide for banners, or the X card size.
  2. Type your headline. Add a subline and a brand name if you want them; the layout adjusts automatically.
  3. Choose a color theme and a background pattern (dots, grid, diagonal lines, rings, or none).
  4. Check the preview. Text wraps and shrinks to fit, so long headlines stay inside the card.
  5. Click Download PNG for the full-resolution file, sized exactly to the preset you picked.
  6. Click Load example to see a filled-in card you can edit.

Common questions

Is the OG image generator really free?
Yes. There is no account, no watermark, and no limit on how many cards you make. The card is drawn on a canvas in your browser, so there is no per-image server cost to recover. Bannerbear charges $49 a month because it runs an API for generating images at scale; this tool generates them one at a time, on your device, for nothing.
What sizes does it support?
Four: 1200x630, the classic Open Graph size that most sites use for link previews; 1080x1080, the square size for social feeds; 1600x900, a wide banner size; and 1200x675, the card size X uses. The download is always exactly the preset dimensions, so the image will not be cropped or letterboxed by the platform.
What happens if my headline is too long?
It wraps to multiple lines, and if it still does not fit, the text shrinks until it does. The layout is computed from the actual text you type, so you will never download a card with text running off the edge. The preview shows exactly what the download will look like, at the same proportions.
Can I use my own fonts or upload a background image?
Not in v1. The card uses system fonts so the text renders identically everywhere, and the backgrounds are solid themes with geometric patterns. Custom fonts and image backgrounds would make it an image editor rather than a quick card generator. For most link previews, a strong headline on a clean theme outperforms a busy custom design anyway.
Do I need an account or API key?
No, and there is nothing to sign up for. Bannerbear needs an API key because it generates images on its servers; this tool generates the image in your browser, so there is no server and nothing to authenticate against.
Where is my card data stored?
Your headline, subline, brand, and theme choices are saved automatically in this browser only, using local storage, so your last card is waiting when you come back. Nothing is uploaded to any server. Clearing your browser data removes the saved settings.
What is an OG image, exactly?
The image that shows up when someone shares your link on social media or in a chat app, the big card with a headline and a picture. Sites define it with an og:image meta tag. Without one, platforms pick a random image or none at all, and your link looks unfinished. A dedicated card takes a minute to make and makes the link look intentional.
Can I make cards in bulk?
No. This is a one-card-at-a-time tool, and it says so plainly. Bulk generation, templated APIs, and programmatic rendering at scale are what the $49/month tools exist for. If you need a card for the article you are publishing today, this is faster; if you need a thousand cards, it is not.
